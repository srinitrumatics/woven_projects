# Implementation Plan: Fulfillment & Returns Table Corrections

**Branch**: `wovn_mathu` | **Date**: 2026-06-30 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/016-fulfillment-returns-corrections/spec.md`

---

## Summary

Correct the Fulfillment and Returns tabs on the Order Details page so that all seven sub-tables (Proposals, Customer Quotes, Sales Orders, Shipping Manifests, Invoices, RMAs, Credit Memos) display: exact column order and labels per spec, full-text non-truncating single-line headers, a sticky first column, default Record-ID-descending sort, and 10-per-page pagination. Cross-reference columns (Proposal #, Customer Quote #) in each table are hyperlinked. New interface fields are added to surface API data already returned by the Salesforce `gtherp/generic/tab` endpoint.

---

### Step 1 — `SortableHeader.tsx` micro-fix (1 line)

**File**: `components/ui/SortableHeader.tsx` line 72

**Change**:
```tsx
// Before:
className={`text-${align} block w-full ${truncate ? 'truncate' : ''}`}

// After:
className={`text-${align} block w-full ${truncate ? 'truncate' : 'whitespace-nowrap'}`}
```

This makes all table headers single-line and non-ellipsis without further changes at call sites, as long as `truncate={false}` is passed.

## Key Styling Patterns

### Sticky First Column (copy for every table's first `<th>` and `<td>`)

```tsx
// First <SortableHeader>:
<SortableHeader
  label="Record #"
  field="Name"
  sortConfig={...}
  requestSort={...}
  width={...}
  onResize={handleResize}
  truncate={false}
  className="sticky left-0 z-20 bg-primary-light dark:bg-gray-900"
/>

// First <td> in each row (add sticky-specific bg that mirrors row hover):
<td className={`${tdBoldClass} sticky left-0 z-10 bg-white dark:bg-gray-800`}>
  {/* link or plain value */}
</td>
```

Note: `<tr>` already has `hover:bg-gray-50 dark:hover:bg-gray-700` but sticky `<td>` needs its own background to avoid bleed-through. Use `group` on `<tr>` and `group-hover:bg-gray-50 dark:group-hover:bg-gray-700` on sticky `<td>` if hover transparency is an issue.

### Pagination (copy for every sub-table)

```tsx
// Below the table wrapper div:
{totalItems > ITEMS_PER_PAGE && (
  <Pagination
    currentPage={page}
    totalPages={Math.ceil(totalItems / ITEMS_PER_PAGE)}
    totalItems={totalItems}
    itemsPerPage={ITEMS_PER_PAGE}
    onPageChange={setPage}
    itemName="proposals"  // entity-specific label
  />
)}
```
