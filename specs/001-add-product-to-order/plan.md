# Implementation Plan: Add Product to Order

**Branch**: `001-add-product-to-order` | **Date**: 2026-06-24 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/001-add-product-to-order/spec.md`

## Summary

Extend the existing `AddToOrderModal` component (already wired to the "Add to Order" button on the product detail page) to handle the "no draft orders" state by showing a "Create Order" button. When clicked, it creates a new draft order in Salesforce and immediately adds the current product as an order line — using the same two-step API pattern (`POST` then `PATCH`) that already exists in `app/orders/page.tsx`. A `PermissionGate` wrapping the "Add to Order" button in `ProductInfoCard.tsx` satisfies the RBAC gate requirement.

## Implementation Detail

### Change 1 — `ProductInfoCard.tsx`: Add permission gate

Wrap the "Add to Order" `<button>` with `<PermissionGate requiredPermissions={['order-create']}>`. The fallback is `null` (button is simply hidden for unauthorized users).

```tsx
// Before
<button onClick={() => setIsModalOpen(true)} ...>
  Add to Order
</button>

// After
<PermissionGate requiredPermissions={['order-create']}>
  <button onClick={() => setIsModalOpen(true)} ...>
    Add to Order
  </button>
</PermissionGate>
```

Import `PermissionGate` from `@/components/AppAuthProvider`.

### Change 2 — `AddToOrderModal.tsx`: Add "Create Order" path

**State additions**:
```ts
const [creating, setCreating] = useState(false);
const { success, error: toastError } = useToast(); // already imported
```

**New handler** `handleCreateOrder`:
```ts
const handleCreateOrder = async () => {
  try {
    setCreating(true);
    setError(null);

    // Step 1: Create draft order
    const createRes = await fetch('/api/salesforce/orders', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        accountId,
        contactId,
        Proposal_Requested__c: false,
        Transfer_Order__c: false,
      }),
    });
    if (!createRes.ok) throw new Error('Failed to create order');
    const createResult = await createRes.json();
    const newOrderId = createResult.data?.[0]?.Id ?? createResult.orderId ?? createResult.Id;
    if (!newOrderId) throw new Error('No order ID returned');

    // Step 2: Add product as order line
    const patchRes = await fetch(`/api/salesforce/orders?orderId=${newOrderId}`, {
      method: 'PATCH',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        order: {
          Id: newOrderId,
          Status__c: 'Draft',
          Bill_to_Account__c: accountId,
          Ship_to_Account__c: accountId,
          Inventory_Account__c: accountId,
        },
        orderLines: [{
          Status__c: 'Draft',
          Product_Name__c: product.id,
          Order_Qty__c: quantity,
          Unit_Price__c: product.price,
          Inventory_Account__c: accountId,
          IsTaxable__c: false,
        }],
        accountId,
        contactId,
        isDraft: true,
      }),
    });
    if (!patchRes.ok) throw new Error('Failed to add product to new order');

    success('Order created and product added successfully!');
    onClose();
  } catch (err: any) {
    setError(err.message || 'Failed to create order');
  } finally {
    setCreating(false);
  }
};
```
