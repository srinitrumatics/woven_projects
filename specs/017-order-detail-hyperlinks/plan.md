## Summary

Add `Customer_Order_Id__c` ID fields to the `DebitMemo` and `RTV` TypeScript interfaces in `ReturnsTab.tsx`, add a `canLinkOrders` permission flag, and render `Customer_Order_Name` as a conditional hyperlink to `/orders/{Id}` in both the Debit Memos and RTV sub-tables. Customer Quote hyperlinks for all other sub-tables were completed in spec 016. The Order Line Details page requires no changes (no Customer Order/Quote references present).

## Phase 1: Design & Contracts

### 1a. Data Model

No new entities. The following TypeScript interface additions are required in `ReturnsTab.tsx`:

**`DebitMemo` interface** — add 1 field:
```ts
Customer_Order_Id__c?: string;
```

**`RTV` interface** — add 1 field:
```ts
Customer_Order_Id__c?: string;
```

Both fields are optional (`?`) because the Salesforce API may not always return the ID, and the null guard prevents rendering a broken link.

### 1b. Contracts

No new API routes or external contracts. The Salesforce `gtherp/generic/tab` Returns endpoint is called unchanged. The only change is in the TypeScript interfaces inside `ReturnsTab.tsx`.

### 1c. Quickstart

See [quickstart.md](./quickstart.md) — 6 validation scenarios covering link rendering, null handling, permission guard, and regressions.

## Implementation Steps

### Step 1 — Expand `DebitMemo` interface

**File**: `app/orders/[id]/components/ReturnsTab.tsx`

Add `Customer_Order_Id__c?: string;` to the `DebitMemo` interface after `Customer_Order_Name: string`.

### Step 2 — Expand `RTV` interface

**File**: `app/orders/[id]/components/ReturnsTab.tsx`

Add `Customer_Order_Id__c?: string;` to the `RTV` interface after `Customer_Order_Name: string`.

### Step 3 — Add `canLinkOrders` permission flag

**File**: `app/orders/[id]/components/ReturnsTab.tsx`

Add alongside existing `canLinkProposals` and `canLinkQuotes`:

```tsx
const canLinkOrders = isSuperAdmin || accountType === 'Customer' || accountType === 'NSO' || accountType === 'Hybrid';
```

### Step 4 — Hyperlink Customer Order in Debit Memos sub-table

**File**: `app/orders/[id]/components/ReturnsTab.tsx`

In the Debit Memos `<tbody>`, change the `Customer_Order_Name` cell:

```tsx
<td className={tdClass}>
    {canLinkOrders && dm.Customer_Order_Id__c ? (
        <Link href={`/orders/${dm.Customer_Order_Id__c}`} className="text-primary hover:underline" target="_blank" rel="noopener noreferrer" onClick={(e) => e.stopPropagation()}>
            {dm.Customer_Order_Name || "—"}
        </Link>
    ) : (dm.Customer_Order_Name || "—")}
</td>
```

### Step 5 — Hyperlink Customer Order in RTV sub-table

**File**: `app/orders/[id]/components/ReturnsTab.tsx`

In the RTV `<tbody>`, change the `Customer_Order_Name` cell with the same pattern using `rtv.Customer_Order_Id__c` and `rtv.Customer_Order_Name`.

### Step 6 — Build verification

Run `npm run build` to confirm no TypeScript errors.
