# Implementation Plan: Post-Order Creation Redirect

**Branch**: `002-post-order-redirect` | **Date**: 2026-06-24 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/002-post-order-redirect/spec.md`

## Summary

After a product is successfully added to an order via the `AddToOrderModal` (either to an existing draft or via a newly created draft), automatically navigate the user to the order detail page for that order. Uses `useRouter` from `next/navigation` — the same pattern already used in `app/orders/page.tsx`. One file changed: `app/products/[id]/components/AddToOrderModal.tsx`.

## Technical Context

**Language/Version**: TypeScript / Next.js 15 (App Router)

**Primary Dependencies**: `useRouter` from `next/navigation` (already available), `warning` from `useToast` (already available, just not imported in the modal)

**Storage**: N/A — no data changes

**Project Type**: Next.js 15 web application (App Router)

**Performance Goals**: Navigation should feel instant (SPA transition, no full reload)

**Constraints**: Client-side navigation only; no server redirects; no new API routes

**Scale/Scope**: Single-file change — 4 targeted edits inside `app/products/[id]/components/AddToOrderModal.tsx`

## Implementation Detail

### Changes to `AddToOrderModal.tsx`

**1. Add imports**

```ts
import { useRouter } from 'next/navigation';
// expand useToast destructure:
const { success, warning, error: toastError } = useToast();
```

**2. Initialize router inside component**

```ts
const router = useRouter();
```

**3. Update `handleAddToOrder` — replace `onClose()` with navigation**

```ts
// Before (end of try block):
success("Product added to order successfully!");
onClose();

// After:
success("Product added to order successfully!");
router.push(`/orders/${selectedOrderId}`);
```

**4. Update `handleCreateOrder` — replace `onClose()` with navigation; handle partial failure**

```ts
// Current partial failure path (PATCH fails):
if (!patchRes.ok) throw new Error('Failed to add product to new order');

// Replace with:
if (!patchRes.ok) {
  warning('Order created, but the product line could not be added. Please add it manually.');
  router.push(`/orders/${newOrderId}`);
  return;
}

// Success path (end of try block):
// Before:
success('Order created and product added successfully!');
onClose();

// After:
success('Order created and product added successfully!');
router.push(`/orders/${newOrderId}`);
```

> **Note on `onClose()`**: Once `router.push` fires, the parent component will unmount as the route changes, so calling `onClose()` is redundant. It can be removed from both success paths or left — either is safe since React will clean up the component on navigation.
